內容後台

以 GitHub 權杖登入後，可以直接修改網站的內容與範本。

建立權杖

  1. 開啟 GitHub 的 Fine-grained tokens 建立頁面。
  2. 「Expiration」設為 90 天以內。
  3. 「Repository access」選「Only select repositories」，只選這個網站的 repo。
  4. 「Permissions」中只把「Contents」設為「Read and write」。其他權限不要開啟，Metadata 會自動設為唯讀，這是正常的。
  5. 點「Generate token」，複製產生的權杖，貼到下方的欄位。

權杖等同這個 repo 的鑰匙。只貼在這個頁面，不要貼到聊天、文件或任何檔案中。懷疑外洩時，請立刻到同一個頁面撤銷。

登入

不勾選時，關閉分頁就會登出。共用的電腦請不要勾選。
